# Class 2 Reflection

## Session 2: Role of the Product Manager (PM)

### 1. Role of an AI Product Manager

An AI Product Manager converts a business or user problem into an
AI-enabled product solution.

A PM must be skilled at translating across functions without overlooking
or flattening technical constraints.

### 2. AI Product Stack Overview

The AI product stack discussed in the session is:

**Data → Model → API → UX**

-   **Data:** The raw material for many AI systems.
-   **Model:** Converts data into useful output.
-   **API:** Enables the model to communicate with the actual product.
-   **UX (User Experience):** Ensures the final AI output reaches the
    user in a useful way.

### 3. Example: Netflix Recommendation Engine

The Netflix recommendation engine illustrates how the components work
together in a continuous feedback loop:

1.  **User behaviour** is observed.
2.  Behaviour generates **data**.
3.  The **recommendation model** processes the data.
4.  The system **ranks recommendations** based on context.
5.  Recommendations are presented through the **Netflix UX**.
6.  The **user watches** the recommended content.
7.  User activity generates **feedback and additional data**.
8.  The feedback helps **improve the model**.

**Flow:**

User behaviour → Data → Recommendation model → Ranking and context →
Netflix UX → User watches → Feedback/data → Model improvement

### 4. Analysing an AI Problem Statement

When analysing an AI problem statement or case, the PM needs to consider
four dimensions:

-   **Technology**
-   **Business**
-   **User**
-   **Regulatory**

These dimensions help the PM understand the problem from multiple
perspectives while accounting for technical constraints.

### Reflection

The role of an AI Product Manager goes beyond identifying an AI
capability. The PM needs to connect the business and user problem to a
workable AI-enabled product solution, understand the product stack from
data to user experience, and consider technology, business, user, and
regulatory perspectives when analysing a problem.
